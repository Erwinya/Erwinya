## Featured projects

Pinned on my profile — representative of current work across backend, web, mobile, and desktop.

### [identity-service](https://github.com/Erwinya/identity-service)
JWT-based identity and user management REST API built with Spring Boot. Registration, login, profile access, and a ready local/Docker setup.

### [qms-inspection-service](https://github.com/Erwinya/qms-inspection-service)
Quality Inspection API for planned-to-completed checks, results, and optional NCR linkage. Spring Boot with H2, Docker Postgres, and OpenAPI.

### [qms-board](https://github.com/Erwinya/qms-board)
Next.js quality board for inspection and NCR summaries. Dashboard-style view over the QMS backend services.

### [lot-viewer](https://github.com/Erwinya/lot-viewer)
Browser viewer for lot/inspection CSV metrics with MAD outlier flags. Upload data, explore series, and export summary JSON compatible with the CLI tooling.

### [soycicloviajera-app](https://github.com/Erwinya/soycicloviajera-app)
Flutter mobile client for [Soy Cicloviajera](https://soycicloviajera.com/) — authentication, OpenStreetMap locations, and traveler profiles for a women's cycling-travel community.

### [noteshelf](https://github.com/Erwinya/noteshelf)
NoteShelf — a focused multi-note desktop editor built with Java Swing. Persistent notes, import/export, and a simple UI for daily writing.
